For a fresh slate, the next collection prerequisite is
`.venv/bin/fifth-pick board-preflight` in the existing credential-enabled
terminal. Enter `PREFLIGHT` for one expected zero-credit schedule request.
Before any event-odds request, select a verified event with an open window,
prepare its identity scope, and obtain the explicit budget. The collector
ceiling is five credits for one event-odds request or fifteen for the three
board observations of one event. The separate game-context request is outside
that ceiling and requires its own authorization. See the [runbook](runbook.md)
for the commands.
