# CIDM 6333 Closeout Walkthrough Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the official CIDM 6333 closeout project locally in the isolated `multitool` repository, with six required commits and evidence that distinguishes observed behavior from unobserved TUI interactions.

**Architecture:** A Python 3.14 src-layout package exposes five argparse subcommands. Standard-library tests, uv-managed tools, OpenCode harness files, Python guard scripts, and Markdown evidence remain at the repository root. The OpenCode plugin is only a bridge to the Python guard.

**Tech Stack:** Python 3.14, Astral uv, Ruff, ty, argparse, unittest, Git, OpenCode.

**Spec:** `docs/superpowers/specs/2026-11-19-cidm6333-closeout-design.md` and the official exercise at https://ahuimanu.github.io/CIDM6333/exercises/closeout-walkthrough.html

## Global Constraints

- Run gates in this order: `uv run ruff check`; `uv run ruff format --check`; `uv run ty check`; `uv run python -m unittest discover -s tests`.
- Record actual command output and exit codes. Never synthesize UI prompts, skill/agent traces, permission decisions, or receipts.

## Review Focus

- Unicode passed through base64 and hex must round-trip as UTF-8; pin with codec round-trip tests including `café`.
- Temperature rounding must preserve the required `0 C = 273.15 K` case; pin the exact representation and record the deliberate one-decimal conflict without editing the test.
- Hash file input and verification must distinguish content mismatch from input errors; pin with string, file, and mismatch tests.
- IPv4 networks with very small prefixes and IPv6 must report host boundaries consistently with `ipaddress`; pin both families and invalid CIDR behavior.
- Guard path matching and shell write detection must not confuse unrelated paths with `tests/`; pin allow/block cases and retain actual JSONL receipts.
